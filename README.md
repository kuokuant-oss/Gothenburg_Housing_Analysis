# 哥德堡公寓售價分析與預測

針對瑞典哥德堡 2013–2024 年公寓成交資料的探索分析與機器學習預測專案。

## 資料集

`gothenburg_sold_apartments.zip`，內含每年一個 HTML 檔（2013–2024），每份檔案包含多筆房產列表。執行前請先將第一個 cell 中的 `ZIP_FILE_PATH` 更新為本機路徑。
**來源**: 房源成交數據來自瑞典房產平台 Booli 的公開市場記錄，涵蓋 2013-2024 年，總計76,435筆。由於原始數據為 HTML 格式且由經紀人提報，數據集存在格式不一致、缺失或錯誤的潛在限制。

## 流程說明

### 1. ETL 資料處理

| 步驟 | 說明 |
|------|------|
| 解壓縮 | 從 ZIP 讀取 HTML，依檔名解析所屬年份 |
| 解析 | 從每筆 `property-card` 擷取地址、日期、地區、城市、售價、坪數、房間數、樓層；處理瑞典文月份名稱及單位符號（kr、m²、½） |
| 清理 | 去除重複列、刪除缺少售價/坪數/房間數的資料、套用合理性篩選（坪數 > 10 m²、售價 > 100,000 SEK）、以 IQR 方法移除每坪價格的極端值 |

訓練資料使用 **2013–2023**（約 68,700 筆），**2024 年資料保留為樣本外測試集**。

### 2. 探索性視覺化

| 圖表 | 說明 |
|------|------|
| 售價直方圖 | 以中位數為界，分色顯示高低價分布並標示中位線 |
| 售價 vs. 坪數散佈圖 | 以雙通道自訂色彩映射編碼房間數 |
| 各房間數每坪單價 | 長條圖比較各房間數的平均 SEK/m²，並標示全局中位線 |
| 地區價格比較 | 最便宜 vs. 最貴的前 5 個地區 |

### 3. 特徵工程

從成交日期擷取 `year`、`month`；`floor` 缺值以中位數填補；`district`、`municipality` 進行 One-Hot 編碼，最終共 **586 個特徵**。

### 4. 模型與 2024 樣本外結果

| 模型 | MAE（SEK） | RMSE（SEK） | R² | 偏差（SEK） |
|------|-----------|-------------|----|------------|
| 隨機森林（基準） | 659,182 | 979,402 | 0.638 | −381,000 |
| HistGradientBoosting + log(price) | 557,311 | 870,789 | 0.714 | −346,481 |
| + 事後偏差修正（A） | 537,243 | 842,402 | 0.732 | −267,240 |
| + 高端分層模型（B） | 518,951 | 760,625 | 0.782 | −260,804 |
| + A + B 合併 | 502,860 | 737,222 | 0.795 | −181,562 |
| + 價格趨勢倍數（A + B + C） | 最佳 | 最佳 | ~0.80+ | 最低 |

### 5. 三種改進策略

**A — 事後偏差修正**  
計算 2013–2023 驗證集上的平均殘差，將其從所有 2024 預測值中減去，以修正系統性低估。

**B — 高端分層模型**  
對售價超過 800 萬 SEK 的豪宅單獨訓練一個 `HistGradientBoostingRegressor`，並在 400–800 萬 SEK 區間以平滑混合方式與主模型融合。

**C — 價格趨勢外推**  
對 2013–2023 年每坪中位數價格擬合對數線性趨勢，外推至 2024 年，並將年增倍數乘以預測結果以修正市場漂移。
